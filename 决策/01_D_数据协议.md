### D7 遗留：跨 session 值域漂移探究（2026-09-28 记录，未提交，调查中）

- **已知事实**（实测）：
  - shared facts `pressure_48.npz` 的 `unit = "source_sensor_units"`（占位符）。
  - 同 subject（S10）同日（20260808）连续三 session：S10101 max=1170.9、S10102 max=2429.5、
    S10103 max=3777.3（**3.2× 漂移**），见 `model_inputs/Step2Motion/adapter_v1/pressure_ranges.csv`。
  - MotionPRO `adapter.py` 与 AnySole `pressure.py:110` 的 `PRESSURE_CLIP=1023` 与实测最大 3777
    冲突（高值被截断压平）。
  - FPP pixel_weight 上游静态 vs 现场计算 61–168× 差异与量程缺失同源。
- **待探究问题**（2026-09-28 分析完成，140 session 全量实测）：见下结论。
- **探究结论（2026-09-28，分析 agent 全量实测）**：
  - **3.2× 增加 = 仅峰值变化，整体分布无影响**。S10101→S10103 分位数比值：q50–q99 = 0.78–1.04
    （bulk 恒等；q10–q90 仿射拟合 s=0.948、a=−2.86、R²=0.9989），q99.5/q99.9/max =
    2.53×/3.66×/3.23×——爆发仅在最顶端 0.3–0.5% 样本。
  - **根因 = 单一通道间歇故障（右脚 cell 35 = 第 3 行第 11 列），不是增益漂移**：89/140 session
    （64%）该格 max>1023；77/140（55%）为全场最大格；承载全数据集超 1023 压力质量的 **76.5%**；
    ON 帧 CV 0.10–0.37（邻格 0.24–1.39，恒压平台）；单段连续 343 帧（8.6s）轨到轨电平；
    S10101→S10103 约 90 秒内从静默爬升到 17.4% 帧 >1023。左右脚尾部不耦合
    （corr(log p99.9_L, p99.9_R)=0.171）→ 排除采集板/增益级共模漂移。
  - **bulk 尺度稳定**：median 非零均值跨日期 176.8–248.2（1.4×，体重差异量级）；去 subject 后
    bulk 无时间漂移（ρ=−0.072）；trial 无系统规律（符号检验 p=0.237）。
  - **clip 1023 实测损失**：0.497% 样本（24,848 个）超 1023，被压平值中位 1.8×/p99 13.2×/
    最大 51.3×；每 session 被压平质量占比中位 9.7%、最大 42.9%；其中 **76.5% 来自故障格本身**
    （真正有效高值损失约 23%）。88%（123/140）session 的 value_max>1023。
  - **建议口径**：跨 session 尺度对齐**勿用 max/p99**（被故障格劫持），改用非零均值/p90 稳健统计；
    格级过滤判据（实测有效）= ON 帧 CV<0.4 + 连续 ON>10 帧 + 该格 max>3×同脚其余格 p99。
- **待用户补录的契约事实**（4 条）：① 传感器型号与单 cell 满量程（FSR 每 cell 最大载荷/单位）；
  ② 增益设置——同日 session 间 3.2× 漂移成因（硬件增益档位？每次采集标定差异？）；③ 值 0 语义
  （无压力 vs 无效）；④ 是否所有 session 同硬件同增益（否则跨 session 比较需增益归一化）。
- **影响面**：MotionPRO（clip 截断）/ FPP-Net（sigmoidNorm 分母）/ AnySole（同款 clip）受影响最大；
  Step2Motion 中等（normalizer 吸收 train 内增益）；pressure_tookit 最小（只用二值接触）；PoseTransOpt 不消费压力值。
