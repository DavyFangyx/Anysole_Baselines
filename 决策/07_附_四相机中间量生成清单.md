# 基线模型中间量生成清单（四相机扩展，2026-10-13）

用户按此清单生成 FPP-Net / PoseTransOpt / pressure_toolkit / MotionPRO 的四相机中间量。
命令与 AnysoleWorkspace/README.md「D2 中间量」一节一致；`--cam` 均支持 `1,2,3,4` 或 `all`。
**cam3 路径与文件名冻结零改动**；cam1/2/4 一律落 `cam{N}` 子目录或 `_cam{N}` 文件名。

## 前置（已完成，只校验不重跑）

- facts 4×140（validate 已过）、mask 前端索引 4 相机、AnySole bbox_cam{1,2,4}；
- hrnet cam1/2/3 已齐、**cam4 生成中**——本清单各步骤不依赖 hrnet，可并行跑；
- 31×11 表示层单棵 cam3（D1 #3 裁定），无需按相机重跑；如需校验：
  `python3 AnysoleWorkspace/tool/build_shared.py --mmvp-only --force`。

## 环境对照

| env | 用在哪 |
|---|---|
| bbox_scan | run_rtmpose、MotionPRO gen_bbox |
| mmvp | run_cliff、pressure_toolkit build_inputs |
| depthpro | rgb2depth |
| touch_gait | MotionPRO gen_kps / gen_image_feature / MotionPRO adapter |

## 1. MMVP 共用中间量（FPP-Net / PoseTransOpt / pressure_toolkit 共享）

```bash
# HALPE-26 关键点 → shared/frontends/rtmpose_halpe26/v1（cam3 文件名不变，其余 keypoints_cam{N}）
/data/fangyuxuan/miniconda3/envs/bbox_scan/bin/python AnysoleWorkspace/tool/adapters/mmvp_series/keypoints/run_rtmpose.py --split all --cam 1,2,3,4

# CLIFF 视觉初始化 → CLIFF_results_cam{N}.npz + pressure_tookit 初值
/data/fangyuxuan/miniconda3/envs/mmvp/bin/python AnysoleWorkspace/tool/adapters/mmvp_series/cliff/run_cliff.py --split all --backbone hr48 --cam 1,2,3,4

# DepthPro 深度图 → shared/frontends/depthpro/v1 下 depth_cam{N}（GPU 作业，--skip-existing 可断点续跑）
CUDA_VISIBLE_DEVICES=7 /data/fangyuxuan/miniconda3/envs/depthpro/bin/python -m AnysoleWorkspace.tool.adapters.mmvp_series.depth.rgb2depth --batch-size 4 --skip-existing --cam 1,2,3,4
```

## 2. FPP-Net

```bash
python3 AnysoleWorkspace/tool/adapters/mmvp_series/fpp/build_inputs.py --split all --cam 1,2,3,4
python3 AnysoleWorkspace/tool/adapters/mmvp_series/fpp/build_metadata.py --force   # 相机无关，只跑一次
```

遗留（D3 再议）：FPP pred_contact_smpl 来源仍为 cam3（per-camera FPP 预测产出后替换）。

## 3. PoseTransOpt

```bash
python3 AnysoleWorkspace/tool/adapters/mmvp_series/posetransopt/build_inputs.py --split all --cam 1,2,3,4
```

树落 `model_inputs/PoseTransOpt/adapter_v1/cam{N}/`；内参键 cam3 冻结 `cam3_fx/fy`、其余 `cam{N}_fx/fy`；
per-camera CLIFF/keypoints 由工具自链（第 1 步产物必须先齐）。

## 4. pressure_toolkit

```bash
conda activate mmvp
python3 AnysoleWorkspace/tool/adapters/mmvp_series/pressure_tookit/build_inputs.py --split all --cam 1,2,3,4
```

⚠️ **地面 ROI 是像素量、相机相关**：cam3 沿用审计值 `--floor-roi 868,1178,568,1055`；
cam1/2/4 用工具内置 `default_floor_roi` 或另行按 D6Test_floor 流程审计——待 D3 决策点，先不显式指定。
依赖第 1 步的 depth/keypoints/CLIFF。

## 每步验收

- 数量：per-camera 产物 140 会话（或 4×140 索引行）齐全；
- cam3 既有文件 mtime/内容不动（`ls -lt` 抽查）；
- 形状抽查：bbox (T,8)、keypoints (T,26,3)、CLIFF_results.npz 一行一帧契约、depth png、MotionPRO pressure.npz (T,320,120)；
- 树形态：`model_inputs/<模型>/adapter_v1/cam{N}/<date>/<S#>/<sid>`（MotionPRO/FPP/PoseTransOpt/pressure_toolkit 各自的 README 契约）。
