# 06 协议层与关节定义（2026-10-08）

> 起因：漂移点 m（VP-MoCap 相机系导出）修复过程中暴露"关节定义"层的不一致，本档澄清两个层面，避免再混用"协议"一词。关联：`04_E_评估收尾.md` §3.5 漂移点 p、§8.4。

## §1 协议层（合约层）——此前所有"同一套协议"表述所指，至今成立

| 模型 | 输出协议 | 配对 GT | 说明 |
| --- | --- | --- | --- |
| AnySole（主模型） | smpl24 | SMPL GT（`motion_neutral_smpl.npz`） | `pred_pelvis_trans` = 预测的根平移 |
| MotionPRO | smpl24 | 同上 | FRAPPE 输出（anysole 体系内训练/评估） |
| MMVP_VP-MoCap | smpl24 | 同上 | PoseTransOpt 优化 pose/beta/trans |
| MMVP_pressure_toolkit | smpl24 | 同上 | SMPL_MMVP 拟合 |
| Step2Motion | bvh23 | BVH GT | 根轨迹 = cumsum(位移)，无世界锚（漂移点 o） |
| MMVP_FPP-Net | V2T | press2Cont | 无关节（压力/接触） |

**合约层 = 输出契约**：协议名（`motion_protocol`）、关节名表（SMPL-24）、单位（世界系米制）、坐标系元数据（`world_z_up`）、公共 evaluator、指标集。此层面四个 SMPL 模型为同一套协议（smpl24），01 文档、E2 矩阵、E4 表述均以此为准。

## §2 实现层（关节定义）——2026-10-08 排查发现的不一致（漂移点 p）

协议只规定"24 个 SMPL 关节、世界系米制"，**未规定**这 24 个数值如何从 SMPL 参数（pose/betas/transl）算出。存在两种实现：

- **协议 GT 链（消费侧，权威）**：`anysole/utils/geometry.py fk_pose6d_np`——骨盆 = transl（根平移，不加旋转）；其余 23 关节沿父链 `R_parent @ offset` 累加，offset = 父相对休息位姿差（`rest_joints[j] − rest_joints[parent]`）。
- **smplx（回归关节）**：`joints = J_regressor @ (v_shaped + v_posed)` 再经 batch_rigid_transform；`joints[0] = transl + J_root`，回归骨盆 J_root ≈ (−0.002, −0.223, +0.028)——SMPL 模型原点在**髋中心**，骨盆关节位于其下方 22.3cm。

实测（同一份 GT pose 参数跑两条链）：逐关节差 **215–317mm**（骨盆 225、髋 ~228、膝 ~260、踝 ~307、头 ~216），其中 ~220mm 均匀底 = 根语义差（沿父链传导至全部关节）。

**三项核验（2026-10-08 实测）**：

1. **树定义一致**：协议 `JOINT_PARENTS` 与 smplx `parents` 逐项相同；
2. **根语义差 = 225mm**：协议 pelvis = `model_trans + J_root`（J_root 不被根旋转作用）；smplx `joints[0] = transl + J_root`——调用方若把骨盆位置当 transl 传入（如拿 `trans_m` 直接喂 smplx），根即双计 J_root（|J_root| = 225mm），并沿父链传导至全部关节；
3. **beta 口径差 ≤ 86mm**：协议链 offsets 用 GT 档案 betas 计算（受试者真实 betas 使 rest_joints 最大位移 86mm、offset 最大差 49mm）；smplx 用调用方传入的 betas。同一 pose、根语义对齐、beta=0 双方时两链残差 ≤ 8mm；beta 口径不一致时踝/脚差 ~77–88mm。

即"关节定义不一致" = 根语义（225mm）+ beta 口径（~80mm）两个实现差异的组合，树本身并无分歧。修复方式 = 导出器调用协议链自己的 `fk_pose6d_np` + GT 档案 offsets/parents，三个口径一次对齐。

## §3 为什么此前未发现

1. **检验 gate 全在协议层**：归档键名、关节名表、单位、坐标系元数据、能力矩阵——"同一份 pose 跑两条实现逐关节数值对比"从未进过验收清单。
2. **覆盖不足**：VP-MoCap 正式导出长期 1/36，全量 MPJPE 数值未产出过。
3. **被大误差掩盖**：4.3m 相机系偏移主导一切指标，0.22m 定义差为其 ~5% 次级项；坐标系修复完成后才可观测（pressure_tookit 1.8m、Step2Motion 0.9m 同理）。
4. **教训**：E1 导出验收应补一条——"导出器关节定义必须与协议 GT 链同一函数对象（`fk_pose6d_np` + 同一 offsets/parents）"，已并入 `04_E` §8.1（E1-附）。
